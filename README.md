# COVID-19-Data-Analysis-Project

This repository contains an end-to-end data analysis project based on global COVID-19 data.

The goal of this project is to explore global cases, deaths, and infection rates, and present key insights through an interactive dashboard.

##Tools Used
- SQL (Data Exploration)
- Tableau (Data Visualization)

## Project Structure
- sql/ : SQL queries used for data exploration and analysis
- tableau/ : Tableau dashboard file and preview image

## Key Questions Explored
- What are the total global COVID-19 cases and deaths?
- Which continents recorded the highest total deaths?
- What percentage of the population was infected in each country?
- How did infection rates change over time?
